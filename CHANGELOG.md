# Changelog

All notable changes to this project are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this project uses
[Semantic Versioning](https://semver.org/).

## [0.1.0] - 2026-09-30

### Added
- Interactive search-as-you-type mode with live, ranked results, question history and `:commands`.
- One-shot mode with streaming output and `--json`.
- Line mode (`--no-live`) for piped input.
- Per-question decision cache.
- Welcome banner.
